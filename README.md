# Mini World Game (Python + Pygame)

Мини-игра: кадры персонажа автоматически вырезаются из `player.jpg`, есть анимации `walk / run / jump`, а перемещение идет по карте `world.png` с коллизиями зданий.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Управление

- `W A S D` или `↑ ← ↓ →` — ходьба
- `Shift` — бег
- `Space` — прыжок

Сквозь здания пройти нельзя.
