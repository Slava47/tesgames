# Mini RPG (Python + Pygame)

Небольшая игра: персонаж может ходить и прыгать по миру, а кадры игрока автоматически вырезаются из `player.jpg` в папку `sprites/player`.

## Запуск

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Запустите игру:

```bash
python main.py
```

## Управление

- `A / D` или `← / →` — ходьба
- `W` / `Space` / `↑` — прыжок
